# 💪 Из пасанов в паханов (Telegram Mini App)

> **Трекер дисциплины и дуэль двух друзей: Даня (`@znkssmt`) vs Миша (`@hansahools`).**  
> Каждый день оба отмечают, кто сегодня сделал всё чётко (**💪 Пахан**), а кто дал слабину (**🍼 Малой**). Когда **оба** сделали выбор за день — открывается персональная карточка с фото и цитатой, а день идёт в зачёт недели, месяца и года!

## 🤝 Инструкция для совместной работы (Даня + Миша в Antigravity)

### 1. Как Мише склонировать проект в Antigravity
1. Зарегистрировать аккаунт на [GitHub](https://github.com).
2. Даня добавляет аккаунт Миши в коллабораторы репозитория:
   * На странице `https://github.com/donatella0101/pakhan_app` → **Settings** → **Collaborators** → **Add people** → ввести ник Миши на GitHub.
   * Миша принимает приглашение (придёт на почту или по ссылке `https://github.com/donatella0101/pakhan_app/invitations`).
3. В **Antigravity** у Миши:
   * Склонировать репозиторий и установить зависимости:
     ```bash
     git clone https://github.com/donatella0101/pakhan_app.git
     cd pakhan_app
     npm install && cd frontend && npm install && cd ../backend && npm install && cd ..
     ```
   * Открыть папку `pakhan_app` как активный Workspace в Antigravity.

### 2. Локальный запуск для разработки
```bash
npm run dev
```
* **Frontend:** `http://localhost:5173`
* **Backend API:** `http://localhost:3001`

> **Важно про `BOT_TOKEN` при локальной разработке:**  
> Настоящий бот `@pakhan_duel_bot` уже крутится 24/7 на сервере Render. Поэтому локально файл `.env` с боевым `BOT_TOKEN` создавать **не нужно** (иначе локальный запуск перехватит соединение Telegram у боевого сервера).  
> В браузере на `http://localhost:5173` в шапке есть переключатель профиля **«Тест: Даня / Миша»** (`🔁`), который позволяет тестировать интерфейс и за Даню, и за Мишу без Telegram!

### 3. Как выкатывать обновления на боевой сервер (Render)
Репозиторий подключён к **Render** (`https://pakhan-app.onrender.com`). Любой пуш в ветку `main` автоматически собирает и обновляет бота и Mini App за ~1–2 минуты:
```bash
# Перед началом работы всегда подтягиваем свежие изменения:
git pull origin main

# После правок проверяем сборку и пушим:
npm run build
git add .
git commit -m "описание изменений"
git push origin main
```

Планировщик `node-cron` работает по часовому поясу `Europe/Moscow`:
* **08:00 МСК:** *«вставай шанцунг ты должен вспахать поле в сто тысяч гектаров»*
* **23:00 МСК:** *«кабанчиком отчитались и спать»*
* Команды для ручной проверки в боте: `/test_morning` и `/test_notify`.

## 📂 Структура проекта

│   ├── src/
│   │   ├── components/
│   │   │   ├── Header.tsx         # Шапка «Из пасанов в паханов», карточки Д vs М
│   │   │   ├── StatsOverview.tsx  # Вкладки Неделя / Месяц / Год + шкала перетягивания
│   │   │   ├── WeekStrip.tsx      # Полоска из 7 квадратиков текущей недели

│   │   │   ├── OutcomeModal.tsx   # Полноэкранная карточка исхода дня
│   │   │   └── DayModal.tsx       # Просмотр/редактирование любого дня из календаря
│   │   ├── telegram.ts            # Telegram WebApp SDK + Haptics
│   │   └── App.tsx                # Корневой компонент и синхронизация состояния
├── Dockerfile                     # Сборка контейнера для деплоя
├── render.yaml                    # Конфигурация Render
