# 👑 Пахан vs Малой (Telegram Mini App)

> **Трекер дисциплины и дуэль двух друзей.**  
> Каждый день отмечаешь, кто сегодня сделал всё чётко (**👑 Пахан**), а кто обленился (**🍼 Малой**). В конце недели, месяца и года приложение коронует главного Пахана!

---

## 🚀 Быстрый старт

### 1. Установка зависимостей (уже выполнены в проекте)
```bash
cd /Users/Berserk/.gemini/antigravity/scratch/pakhan-app
npm run build
```

### 2. Запуск в режиме разработки
```bash
npm run dev
```
* **Frontend:** `http://localhost:5173`
* **Backend API:** `http://localhost:3001`

Приложение можно открыть прямо в браузере — встроен режим **демо-пользователя**, поэтому интерфейс работает даже без открытия из Telegram!

### 3. Запуск продакшен-сервера (всё на одном порту 3001)
```bash
npm start
```
* Откройте `http://localhost:3001` — сервер сразу отдаёт готовый фронтенд и API.

## 🤖 Как подключить настоящего Telegram-бота

### Шаг 1. Создание бота
1. Откройте в Telegram [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot`, укажите имя и юзернейм (например, `MyPakhanDuelBot`).
3. Скопируйте полученный **API токен**.

### Шаг 2. Добавление токена в проект
В файле `backend/.env` укажите токен:
```env
BOT_TOKEN=123456789:ABCDefGhIJKlmNoPQRsTUVwxyZ
WEBAPP_URL=https://your-domain-or-tunnel.com
PORT=3001
```

### Шаг 3. Настройка Mini App кнопки в BotFather
1. В [@BotFather](https://t.me/BotFather) напишите `/mybots` -> выберите вашего бота.
2. Нажмите **Bot Settings** -> **Menu Button** -> **Configure menu button**.
3. Отправьте ссылку на ваше веб-приложение (например, с ngrok/cloudflared или Vercel).
4. Укажите название кнопки, например: `👑 Битва Паханов`.

### Для локального тестирования из Telegram (бесплатный HTTPS туннель):
Установите бесплатный `cloudflared` или `ngrok`:
```bash
# Через Cloudflare Tunnel (без регистрации):
npx cloudflared tunnel --url http://localhost:5173

# Или через ngrok:
ngrok http 5173
```
Полученную HTTPS-ссылку вставьте в `WEBAPP_URL` в `backend/.env` и в [@BotFather](https://t.me/BotFather).

## 🎮 Как работает механика

1. **Создание дуэли:**
   * Первый участник открывает приложение.
   * Нажимает **«Позвать»** или **«Позвать кореша на дуэль»**.
   * Отправляет сгенерированную ссылку другу в Telegram.
2. **Второй участник залетает:**
   * Друг открывает ссылку — пара сохраняется в базе SQLite.
3. **Ежедневный отчёт:**
   * Каждый участник сам выбирает свой статус: **[👑 Я Пахан]** или **[🍼 Я Малой]**.
   * При выборе «Пахан» взрывается конфетти 🎉 и срабатывает тактильная вибрация Telegram Haptics.
   * Если друг ещё не отметил свой день, доступна кнопка **«Пнуть кореша»** (отправляет уведомление в Telegram).
4. **Календарь дней:**
   * Интерактивная сетка любого месяца.
   * Отметки исходов: `👑 👑` (Два Пахана), `👑 🍼` (Победа дня), `🍼 🍼` (Два Малых).
   * Клик по любому дню позволяет посмотреть или изменить статус за эту дату.
5. **Титулы и статистика:**
   * **Пахан недели** (подсчёт понедельник–воскресенье).
   * **Пахан месяца** (сводка за месяц и прогресс-бар).
   * **Пахан года** (годовой кубок дисциплины).
6. **Напоминания:**
   * Встроенный планировщик (cron) каждый вечер в 21:00 напоминает зайти и зафиксировать статус дня.
